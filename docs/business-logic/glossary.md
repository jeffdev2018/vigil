# Glossaire — Organisation

| Terme | Sens retenu pour l'audit |
|---|---|
| Espace de travail | Périmètre partagé d'identités, projets et droits |
| Organisation / structure | Configuration versionnée de coordination d'un projet ou du workspace par défaut |
| Équipe | Groupe avec mission, responsables, appartenances et politiques ; OrgUnit dans le code |
| Acteur | Personne ou agent existant dans l'espace |
| Appartenance | Association acteur-équipe, distincte d'une identité et de la responsabilité humaine |
| Rôle | Responsabilité définie dans une équipe ; son titulaire est une affectation |
| Responsable humain | Supervise une équipe ou structure ; pas nécessairement membre du roster |
| Destinataire | Acteur ou squad retenu pour une demande |
| Squad | Ressource d'exécution distincte de l'équipe, avec leader et agents |
| Relation | Lien typé ; effet réel distinct de sa représentation |
| Modèle | Terme actuel mêlant topologie, gouvernance, sélection et temporalité |
| Vue / chart | Projection visuelle ; ne doit pas modifier la sémantique |
| Révision | Définition persistante ; métadonnées actuellement incomplètes |
