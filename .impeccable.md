# Design Context

Contexte fourni dans la conversation par le porteur du projet, 8 septembre 2026.

- Public : petites équipes mêlant collaborateurs humains et agents IA ; le parcours Organisation doit rester compréhensible pour un non-développeur.
- Tâches : composer les équipes, affecter les participants, définir responsabilités et modes de coordination, comprendre le routage puis suivre le travail.
- Ton attendu : une interface « magnifique », « user friendly », attirante et interactive. La confiance et la clarté du parcours sont indispensables ; un habillage visuel ne compense pas une incohérence métier.
- Contraintes connues : application de travail existante, thèmes clair et sombre, navigation et composants partagés web/desktop ; données existantes conservées.
- Exigence utilisateur complémentaire : cohérence de tous les composants UI d'Organisation. Réutiliser la bibliothèque React partagée `packages/ui` (Base UI / shadcn), notamment les menus déroulants ; remplacer les sélecteurs HTML natifs disparates dans ces écrans. Harmoniser boutons, onglets, champs, cases à cocher et panneaux, y compris les états de focus, erreur, chargement et désactivation. Les longues listes d'acteurs/équipes doivent être recherchables. Vérifier visuellement les menus ouverts, dans les thèmes clair et sombre et dans les panneaux/dialogues.
- Audit actuel : vérifier les parcours et la couverture fonctionnelle complète avant une nouvelle implémentation. Aucune nouvelle direction artistique n’est considérée approuvée par cet audit.
