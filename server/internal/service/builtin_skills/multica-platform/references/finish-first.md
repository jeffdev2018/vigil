# Finish-first and Workspine-lite

When the task involves multiple sub-tasks, @-mentions, agent hops, or a Git
workdir plan, open the dedicated skill **`multica-finish-first`** (including
`references/workspine.md` there).

That skill owns the soft protocol: validate the current Multica issue or plan
step before fan-out, and keep durable plans under `.multica/plans/` or
`docs/agent-plan/`.

For Plan Gate publish/verify commands, open **`multica-plan-verification`**.
