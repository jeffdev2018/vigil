Multica 中的会议就是一段录制的对话。音频在进行过程中被转录，停止时被摘要，其中包含的每一项承诺都会作为待处理项进入 Triage 队列，你可以将它接受为任务，也可以忽略。

<Callout type="info">
音频从不保存。每个片段被转录后即丢弃；保留下来的只有文字、摘要和行动项。
</Callout>

## 录制

**会议 → 录制会议**会开始一次录制。浏览器会先请求麦克风权限，然后提示共享标签页或窗口，以便同时收录其他参与者——拒绝也没关系，此时会议只用你的麦克风录制，录制器会明确提示这一点。

录制指示器会在每个页面上保持可见，因此你可以离开当前页面之后仍能停止录制。停止操作会结束这场会议：上传对话的最后部分、写入摘要、把行动项排入队列。

只有发起录制的那个标签页持有这次录制。其他人，或同一个人在另一个标签页，会看到"这场会议正在别处录制"。

<Callout type="warn">
请告知参会者他们正在被转录。录制器会显示同样的提醒——征得同意是你的责任，不是产品的责任。
</Callout>

### 录制中断时

会议进行到一半关闭标签页，会议会停留在 `recording` 状态，且没有别的方式能结束它——录制器只存在于那个页面里。打开这场会议，使用**结束会议**：录制人本人，以及任何工作区管理员或所有者都可以执行这个操作。截至那一刻已经转录的内容会照常被摘要。

如果摘要一直没有返回（服务器重启了，或当时没有配置模型），会议会停留在 `summarizing` 状态。五分钟后，页面会停止等待并提供**重新生成摘要**，它会重新执行同一次处理。由此产生的行动项会并入已经在队列中的项目，而不是产生重复。

## 桌面客户端的会议检测

桌面客户端能够察觉到会议软件（Zoom、Meet、Teams、Slack huddles、FaceTime 以及各种浏览器）占用了麦克风，并提示是否要记录笔记。它只会提示，从不会自行开始录制；当 Multica 自己正在录制时，它会保持安静。

检测在 macOS 上使用内置的 CoreAudio 助手，在 Linux（PulseAudio / PipeWire）和 Windows 上则使用操作系统自身的录制流列表。可以在**设置 → 偏好设置 → 会议 → 自动检测会议**中关闭；关闭后客户端会完全停止监听麦克风。

## 实时转录与批量转录

转录有两条路径，具体走哪一条取决于服务端的配置。

- **批量**始终会被使用：音频以约 30 秒为单位的片段上传，每个片段到达后就被转录。当服务商支持说话人标注并已启用时，转录会标出说话人——会议页面会按每次发言切换渲染一个段落。
- **实时**在配置了实时模型时运行：浏览器使用服务端签发的短期令牌，直接打开服务商的实时 socket，文字会随着说话即时出现。实时转录不带说话人标注。如果 socket 断开，录制会转到批量路径继续进行。

会议页面上，转录默认是折叠的——上方的摘要通常才是你真正想看的内容。

## 摘要与行动项

停止会议会把转录发送给工作区的语言模型，模型会返回一份简短的 markdown 摘要（决定事项、待解决问题、下一步）以及最多 15 个行动项。只有当模型能够指出转录中支撑该行动项的原文片段时，这个行动项才会被保留。

每个行动项会变成一条**待处理的 triage 项**，而不是任务：需要有人来判断。接受后会创建一个任务，标记着它来自哪场会议，该任务上会显示一个"来自会议"的链接，指回这段录制。

如果没有配置模型，或调用失败，会议仍然会正常完成，转录也会保留——页面会提示没有生成摘要，并提供**重新生成摘要**，供以后有可用模型时使用。

## 配置

会议功能需要一个语音转文字（speech-to-text）服务商。任何兼容 OpenAI 的 `POST {base}/v1/audio/transcriptions` 接口的服务都可以：Mistral Voxtral、OpenAI、Groq，或者部署在 vLLM 之后的自托管 Whisper / Qwen3-ASR。

| 变量 | 说明 |
| --- | --- |
| `MULTICA_STT_BASE_URL` | 服务商的基础 URL。留空会禁用会议和语音备忘录。 |
| `MULTICA_STT_API_KEY` | 服务商的 API 密钥。 |
| `MULTICA_STT_MODEL` | 转录模型。留空同样会禁用该功能。 |
| `MULTICA_STT_LANGUAGE` | ISO 639-1 语言提示（如 `fr`）。留空则由服务商自动检测。 |
| `MULTICA_STT_DIARIZE` | 设为 `true` 会要求支持该功能的服务商（Voxtral）标注说话人。 |
| `MULTICA_STT_REALTIME_MODEL` | 用于逐词实时转录的模型。留空会禁用实时路径。 |

没有配置服务商时，API 会返回 `409 stt_not_configured`，UI 会用一条不显眼的提示把该功能隐藏起来，而不是在上传时报错。

其余的自托管配置参见[环境变量](/docs/environment-variables)。
