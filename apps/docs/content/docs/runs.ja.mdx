**実行**はエージェントの作業単位です。1つの実行は、1つのランタイム上で1体のエージェントが1件の課題（あるいは1回のチャットのやり取り、1回のオートパイロットの起動）に取り組むことを指します。これまでは課題ごとにしか見えませんでした。**実行**はフリート全体を映し出します。

## ページの内容

サイドバーの**実行**（*AIチーム*の下）は、ワークスペースのエージェントが行ったすべての実行を新しい順に一覧表示し、ヘッダーでフリートを一目で把握できます。キュー中、実行中、人でブロック中がそれぞれ何件か、そして（UTCの）午前0時以降に完了・失敗・キャンセルされた件数、今日開始されたものすべての費用が表示されます。

各行にはエージェントと課題が表示され、実行の状態と経過時間、使用状況が報告されていればその費用、そして——最も重要な列である——**何にブロックされているか**が示されます。

- **承認ゲート**（git push、機微なツール呼び出し、支出）— 依頼へのリンク付き。
- 実行が発行した**Decision Card**。
- **ゴールに関する質問**、または課題の**保留中のステータス変更**。
- 別の実行が保持している**ローカルディレクトリ**、**一時停止**、または**延期**。

ブロック要因をクリックすると、[その場で判断できる](/decisions#where-you-answer)依頼が開きます。しばらく活動が報告されていない実行中の実行はサイレントとしてフラグが付きます。

フィルターで状態（実行中、完了、すべて）、エージェント、課題、ランタイムによって一覧を絞り込めます。一覧はカーソルでページングされるため、長い履歴が一度に読み込まれることはありません。

## 実行を止める

行を選択して**キャンセル**を押すと停止できます。各実行はそれぞれ1行ずつ結果が報告されます——キャンセル済み、すでに終了済み、見つからない——ため、40件のキャンセルのうち3件目が止められなくても、そこで処理が止まったりはせず、その旨が報告されます。キャンセルはデーモンの次のポーリングで届き、その後エージェントのプロセスに終了シグナルが送られます。

**キルスイッチ**（オーナーと管理者向け）は1回の操作で、この順序で2つのことを行います。まず**フリートを停止**し——新しい実行は受け付けられず、進行中のすべてのゲート付きアクションが拒否されます——次に、終了していないすべての実行を**キャンセル**します。理由の入力を求められ、その理由はオーナーまたは管理者が停止を解除するまでバナーとしてすべての課題に表示されます。解除はバナー、実行ページ、または**設定 → ワークスペース**から行えます。どちらの操作も監査されます（`runs.kill_switch`、`run_halt.changed`）。

<Callout title="停止が行わないこと">
停止だけでは、すでに実行中のものは何も止まりません。新しいクレームとゲート付きアクションを拒否するだけです。だからこそ、常時オンにしておいても安全なのです。キルスイッチは、停止に加えてキャンセルを行うものです。
</Callout>

## CLI

```bash
multica runs list                 # runs in flight
multica runs list --terminal      # finished runs
multica runs list --agent <id> --limit 20 --output json
multica runs cancel <run-id> [run-id...]
```

キルスイッチにはコマンドがあえて用意されていません。人がアプリ内で下す判断だからです。

## API

- `GET /api/runs?state=active|terminal|all&status=&agent_id=&issue_id=&runtime_id=&since=&cursor=&limit=` — `{runs, next_cursor, summary}`。各実行は `agent_name`、`issue{id, identifier, title, status}`、`usage[]`、`cost_usd_ticks`、`duration_ms`、`silence_ms`、`blocked_on{kind, id, decision_id, summary, since}` を持ちます。
- `POST /api/runs/cancel {task_ids}` — `{cancelled, results[{task_id, outcome, error?}]}`。
- `POST /api/runs/kill-switch {reason}` — オーナーと管理者のみ。`{run_halt, cancelled, results}`。
- `GET/PUT /api/run-halt` — 停止状態単体の読み取り・設定。

メンバーには自分が見ることのできるエージェントの実行のみが表示され、非公開エージェントの実行は一覧から外れます。イベント `task:*` と `run_halt:changed` により、開いているページが最新の状態に保たれます。
