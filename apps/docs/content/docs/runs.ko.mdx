실행은 에이전트 작업의 단위입니다. 하나의 실행은 하나의 에이전트가 하나의 런타임에서 하나의 이슈(또는 채팅 한 턴, 오토파일럿 트리거 한 번)를 처리하는 것입니다. 지금까지는 이슈별로만 볼 수 있었습니다. **실행**은 전체 에이전트 함대를 보여줍니다.

## 페이지

사이드바의 **실행**(*AI 팀* 아래)은 워크스페이스의 에이전트가 수행한 모든 실행을 최신순으로 나열하며, 헤더에서 전체 현황을 한눈에 볼 수 있습니다: 대기 중, 실행 중, 사람에 의해 막힌 것이 각각 몇 건인지, 그리고 자정(UTC) 이후 완료·실패·취소된 건수와 오늘 시작된 모든 실행의 비용이 표시됩니다.

각 행에는 에이전트와 이슈가 표시되고, 실행의 상태와 진행 시간, 사용량이 보고된 경우 그 비용, 그리고 — 가장 중요한 열인 — **무엇에 막혀 있는지**가 나타납니다:

- 요청 링크가 달린 **승인 게이트**(git push, 민감한 도구 호출, 지출);
- 실행이 발행한 **Decision Card**;
- **목표 질문** 또는 이슈의 **보류 중인 상태 변경**;
- 다른 실행이 점유한 **로컬 디렉터리**, **일시 정지**, 또는 **연기**.

막힌 항목을 클릭하면 [그 자리에서 판단할 수 있는](/decisions#where-you-answer) 요청이 열립니다. 한동안 활동이 보고되지 않은 실행 중인 실행에는 무응답 표시가 붙습니다.

필터로 상태(진행 중, 완료, 전체), 에이전트, 이슈, 런타임별로 목록을 좁힐 수 있습니다. 목록은 커서로 페이징되므로 긴 이력이 한 번에 모두 로드되지 않습니다.

## 실행 멈추기

행을 선택하고 **취소**를 누르면 멈춥니다. 모든 실행은 각자 한 줄로 결과가 보고됩니다 — 취소됨, 이미 끝남, 찾을 수 없음 — 그래서 40건을 취소하다가 세 번째 건을 멈출 수 없더라도 거기서 멈추지 않고 그렇게 보고합니다. 취소는 데몬의 다음 폴링 때 전달되고, 그 후 에이전트 프로세스에 종료 신호가 전달됩니다.

**킬 스위치**(오너와 관리자 대상)는 한 번의 조작으로 다음 두 가지를 이 순서로 수행합니다: 먼저 **전체를 정지**시킵니다 — 어떤 실행도 새로 시작되지 않고, 진행 중인 모든 게이트 작업이 거부됩니다 — 그다음 아직 끝나지 않은 모든 실행을 **취소**합니다. 이유를 입력해야 하며, 그 이유는 오너나 관리자가 정지를 해제할 때까지 모든 이슈에 배너로 표시됩니다. 해제는 배너, 실행 페이지, 또는 **설정 → 워크스페이스**에서 할 수 있습니다. 두 조작 모두 감사 로그에 남습니다(`runs.kill_switch`, `run_halt.changed`).

<Callout title="정지가 하지 않는 것">
정지만으로는 이미 실행 중인 것을 아무것도 멈추지 못합니다: 새로운 시작과 게이트 작업을 거부할 뿐입니다. 그래서 계속 켜 두어도 안전합니다. 킬 스위치는 정지에 취소를 더한 것입니다.
</Callout>

## CLI

```bash
multica runs list                 # runs in flight
multica runs list --terminal      # finished runs
multica runs list --agent <id> --limit 20 --output json
multica runs cancel <run-id> [run-id...]
```

킬 스위치에는 일부러 명령어를 두지 않았습니다: 이는 사람이 앱에서 직접 내려야 하는 결정이기 때문입니다.

## API

- `GET /api/runs?state=active|terminal|all&status=&agent_id=&issue_id=&runtime_id=&since=&cursor=&limit=` — `{runs, next_cursor, summary}`. 각 실행은 `agent_name`, `issue{id, identifier, title, status}`, `usage[]`, `cost_usd_ticks`, `duration_ms`, `silence_ms`, `blocked_on{kind, id, decision_id, summary, since}`를 가집니다.
- `POST /api/runs/cancel {task_ids}` — `{cancelled, results[{task_id, outcome, error?}]}`.
- `POST /api/runs/kill-switch {reason}` — 오너와 관리자 전용; `{run_halt, cancelled, results}`.
- `GET/PUT /api/run-halt` — 정지 상태만 읽거나 설정합니다.

멤버는 자신이 볼 수 있는 에이전트의 실행만 볼 수 있으며, 비공개 에이전트의 실행은 목록에서 제외됩니다. `task:*`와 `run_halt:changed` 이벤트가 열려 있는 페이지를 최신 상태로 유지합니다.
